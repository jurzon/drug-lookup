# DrugLookup

Mini dashboard pre vyhľadávanie informácií o liekoch. Slúži ako jednoduché
front-end rozhranie nad verejným liekovým API (integrácia bude doplnená neskôr).

## Tech stack

- [Vite](https://vitejs.dev/) — dev server a build nástroj
- [TypeScript](https://www.typescriptlang.org/) — typovanie
- Vanilla DOM API — žiadny UI framework

## How to run

Predpoklady: Node.js 20+ a npm.

```bash
# nainštaluj závislosti
npm install

# spusti dev server (default http://localhost:5173)
npm run dev

# produkčný build do dist/
npm run build

# lokálny náhľad produkčného buildu
npm run preview
```
